### 2.3 Ten-Minute Presentation Speech

Good morning/afternoon everyone. I am pleased to present my Final Year Project, Graduate Job Portal SL, which is also referred to as GradConnect SL. This project is a web-based graduate recruitment and job management system developed to support communication and interaction between graduates, employers, and administrators. The main objective of the project is to provide an online platform where graduates can discover job opportunities, build professional profiles, and apply for positions, while employers can publish vacancies, review applicants, and manage hiring processes efficiently. In addition, administrators can monitor and manage users, jobs, applications, and system activities.

The project was selected because the recruitment process remains a critical challenge in many academic and professional environments. Traditional methods of job searching and hiring are often inefficient because they depend on manual processes, scattered information, and weak communication between parties. Graduates may not always know where opportunities are posted, and employers may struggle to manage applicants effectively. Therefore, a centralized and automated platform was identified as a practical and valuable solution.

The system was developed using PHP 8 for server-side logic, MySQL for database management, Bootstrap 5 for responsive interface design, JavaScript for interactivity, and HTML/CSS for page structure and styling. These technologies were chosen because they are widely used, reliable, and suitable for building modern web applications. The architecture of the system follows a layered structure. The presentation layer provides the user interface, the application layer handles business logic and processing, and the database layer stores all system data. This structure makes the system easier to maintain and expand in the future.

The core modules of the system include authentication, graduate management, employer management, job management, job search and filtering, application submission, notifications, admin management, and reporting. In the graduate module, users can register, login, create profiles, upload CVs, and apply for jobs. In the employer module, users can register companies, publish jobs, review applications, and monitor recruitment status. The admin module provides a control center for managing users, jobs, and system content. The notification system supports users by sending updates about application progress and system events. These modules work together to create a complete recruitment ecosystem.

One of the most important aspects of the project is the security and reliability of the system. The application includes secure authentication, role-based access control, input validation, and session-based functionality. The system also ensures that users can only access the areas relevant to their roles. For example, graduates can access their dashboards and apply for jobs, employers can manage their postings, and administrators can manage the wider platform. This role-based design was important for protecting data and improving user experience.

The database design was also a major part of the project. The system uses carefully organized tables to manage users, graduate profiles, employer profiles, companies, jobs, applications, and notifications. Relationships between these tables help maintain integrity and support efficient data retrieval. Proper database structuring was essential, especially because the system involves multiple entities interacting with each other.

During development, I encountered several technical challenges. These included errors in registration flow, inconsistent role-based redirects, issues in navigation, and difficulties in notification handling. I also faced problems related to database query handling during the application process. These issues were solved through debugging, systematic testing, and code review. This experience strengthened my understanding of practical software development and the importance of quality assurance.

The testing process was an important part of the project. I tested the main functions of the system to verify that registration, login, job posting, applications, and notifications work correctly. I also checked that forms behaved properly and that data was stored and retrieved as expected. Although the system is not yet a full-scale commercial product, it demonstrates a strong foundation for future improvement and deployment.

In conclusion, this project successfully demonstrates the development of a functional web-based recruitment management system. It addresses a real-world problem, uses appropriate technologies, and provides a practical solution for graduates, employers, and administrators. The project reflects both technical capability and an understanding of software engineering principles. It has also helped me improve my skills in planning, design, implementation, testing, and documentation.

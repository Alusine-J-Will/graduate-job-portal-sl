# Graduate Job Portal for Sierra Leone

## Project Description

This project is a professional online job portal designed for graduates in Sierra Leone. It will support job discovery, employer recruitment, graduate profiles, and administrative oversight.

## Objectives

- Provide a centralized platform for graduate job opportunities.
- Enable employers to post vacancies and review applications.
- Support graduates in creating professional profiles and applying for jobs.
- Provide an admin panel for system management and oversight.

## Technology Stack

- Frontend: HTML5, CSS3, Bootstrap 5, JavaScript
- Backend: PHP 8 (procedural PHP with reusable modules)
- Database: MySQL
- Environment: XAMPP, Visual Studio Code

## Folder Structure Overview

- admin/: Administrative dashboard and management pages.
- auth/: Authentication pages such as login, registration, and logout.
- assets/: Static frontend resources including CSS, JavaScript, images, and uploads.
- config/: Configuration files such as database and constants.
- database/: SQL schema and database-related files.
- docs/: Documentation, diagrams, and project reports.
- employer/: Employer-specific dashboard and pages.
- graduate/: Graduate-specific dashboard and pages.
- includes/: Shared PHP components and partials.
- layouts/: Reusable layout templates.
- uploads/: Storage for uploaded files such as logos, photos, CVs, and cover letters.
- vendor/: Reserved for future Composer dependencies.

## Installation Instructions

1. Place this project folder inside your XAMPP htdocs directory.
2. Start Apache and MySQL from the XAMPP Control Panel.
3. Open the project in Visual Studio Code.
4. Configure the database connection in config/database.php.
5. Import the SQL file from database/database.sql when the database layer is implemented.
